PySTRA: structural reliability in Python#

PySTRA implements established and selected modern structural reliability methods, with practical tools for code calibration and structural assessment. Define your engineering model in Python, quantify its reliability, and inspect the assumptions and diagnostics behind the result.

These pages describe PySTRA 2.0.0a1, the 2.0 development API. Follow Installation to install this version. What’s new in PySTRA 2.0 summarizes the release, and existing users can consult Migrating from 1.x to 2.0; the stable documentation uses the released 1.x API.

Find the right material#

  • Get started takes you from installation to a checked first result.

  • What’s new in PySTRA 2.0 summarizes what 2.0 adds and changes.

  • User guide helps you choose methods, build models and interpret results.

  • Examples contains worked tutorials and published benchmark problems.

  • API reference describes public objects, parameters, results and extension details.

  • Theory explains the formulations, assumptions and notation.

For method selection, begin with Choosing a reliability method. For unexpected results, see Troubleshooting reliability analyses. To reproduce a paper example, browse the Benchmark catalogue.

Project and community#

PySTRA is GPL-3.0-or-later. Its numerical methods build on the work cited in References, including the original framework [Hackl2013]. See Citing PySTRA and its methods for software citation and method attribution. Report questions and reproducible problems through the issue tracker.
