Complete symbol map#

Every public name in the 1.x baseline that 2.0 renames, replaces, removes or changes, generated from the definition manifest. Names that are not listed keep their name and behavior. Modules marked not in 1.6.0 came from feature branches merged for 2.0; they were never part of a released 1.x version. Start with the checklist in Migrating from 1.x to 2.0: this map is for looking up a particular name.
