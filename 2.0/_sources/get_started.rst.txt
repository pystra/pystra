Get started
===========

Start here if you are new to PySTRA. Basic Python is enough for the first
example; each later tutorial identifies the reliability concepts it assumes.

.. list-table:: Your first steps
   :header-rows: 1
   :widths: 35 65

   * - Step
     - What you will do
   * - :doc:`install`
     - Install the 2.0 development package and check its version.
   * - :doc:`notebooks/ex_first_analysis`
     - Define resistance and load, run FORM and verify the result analytically.
   * - :doc:`guides/models`
     - Adapt the model, distributions and dependence to your problem.
   * - :doc:`guides/results`
     - Inspect convergence, coordinates, probability and numerical uncertainty.

Choose your next task
---------------------

Use :doc:`guides/methods` to select a starting method. The
:doc:`notebooks/ex_intro` tutorial compares FORM, SORM and simulation on a
correlated nonlinear problem. Engineering workflows are covered in
:doc:`guides/calibration` and :doc:`guides/assessment`.

Already using PySTRA 1.x? Read :doc:`migrating` for the breaking API changes.
