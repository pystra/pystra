Code calibration and engineering decisions
==========================================

Define load combinations, calibrate code factors and compare engineering
decisions. Code calibration uses a common sequence: propose factors, generate
code-conforming designs, assess reliability and revise the factors. The
normalized-reliability tutorial evaluates factor sets over load ratios; the
partial-factor tutorial demonstrates factor derivation and verification.
